## Project Contents

Quick overview of the project structure:

- **config/** : Contains configuration files for Jekyll.
- **_includes/** : Contains reusable HTML code snippets included in your pages.
- **_layouts/** : Contains main layouts for your pages.
- **_sass/** : Contains SCSS files for customizing the site's style.
- **_site/** : Contains files generated by Jekyll during site build.
- **_config.yml** : Main configuration file for Jekyll.
- **Gemfile** and **Gemfile.lock** : Files used to manage Ruby dependencies.


## Setting Up Your Development Environment

### Using VS Code:

1. **Install the `Jekyll Run` Extension:**
   - Open VS Code and install the `Jekyll Run` extension.

### Requirements:

- **Check for Ruby Installation:**
  ```bash
  ruby -v
  ```
  Ensure Ruby is installed on your system.

- **Install Ruby Development Package (if needed):**
  ```bash
  sudo apt-get install ruby-dev
  ```
  This package includes necessary header files for compiling Ruby gems.

- **Install Bundler and Jekyll:**
  ```bash
  sudo gem install bundler jekyll
  ```
  Bundler manages your gem dependencies, and Jekyll is the static site generator.

- **Install Gemfile Dependencies:**
  ```bash
  sudo bundle install
  ```
  This command installs dependencies specified in your project's Gemfile.

### Ready to Start!

You're now prepared to begin working on your project using Jekyll in VS Code!
